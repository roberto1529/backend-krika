# **Backend - Gestión de Tareas**

## **Descripción**

Este es el backend de la aplicación de gestión de tareas, construido con Node.js y Express.js. El backend gestiona las operaciones CRUD de las tareas y la autenticación de usuarios mediante JWT. Además, gestiona los usuarios y la base de datos Mysql para almacenar las tareas y la información del usuario.

## **Tecnologías utilizadas**

- **Node.js**: Entorno de ejecución para el servidor.
- **Express.js**: Framework para la creación de la API RESTful.
- **Sequelize**: ORM para interactuar con la base de datos PostgreSQL.
- **PostgreSQL**: Base de datos relacional.
- **JWT (JSON Web Token)**: Para la autenticación y autorización de usuarios.
